---

## 🔒 Safe Handling of API Keys & Secrets

- **Never commit `.env` files or hardcoded API keys.**
- The project includes `.gitignore` and `.env.example` to prevent accidental credential commits.
- If you accidentally commit an API key, revoke it immediately via the [Google Cloud Console Credentials Page](https://console.cloud.google.com/apis/credentials).

---

## 🛡️ Reporting a Vulnerability

If you discover a security vulnerability within the **YouTube Analytics & Trends Platform**, please do not open a public issue. Instead, report it privately to the maintainers:

- **Maintainer:** Dhanushree-1977
- **Email:** [dhanushreevm63@gmail.com](mailto:dhanushreevm63@gmail.com)

Please provide:
1. Description of the vulnerability.
2. Steps to reproduce the issue or proof-of-concept.
3. Potential impact of the issue.

We will acknowledge receipt within 48 hours and provide an estimated timeline for remediation.
